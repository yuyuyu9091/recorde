# 목소리 책장

부모가 그림책을 읽어 녹음해 두면, 아이가 책 표지를 눌러 그 목소리를 듣는 웹앱이에요.
아이는 실물 책을 펼쳐 놓고 듣다가 **"띵" 소리가 나면 책장을 넘기면** 돼요.

- 안드로이드 태블릿 + 크롬 기준으로 만들었어요.
- 녹음과 표지 사진은 **태블릿 안에만** 저장돼요. 서버나 계정이 필요 없어요.
- 대신 태블릿을 초기화하거나 잃어버리면 녹음이 사라지니, **백업 파일을 꼭 만들어 두세요** (아래 5번).

---

## 1. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 모든 화면의 뼈대 (책장, 듣기, 부모 화면, 녹음 화면, 비밀번호) |
| `css/style.css` | 색과 모양. 맨 위 `:root`에서 색을 바꿀 수 있어요 |
| `js/app.js` | 버튼 동작과 화면 전환 |
| `js/db.js` | 저장소 (태블릿 브라우저의 IndexedDB) |
| `js/recorder.js` | 녹음 + 책장 넘김 위치 기록 |
| `js/player.js` | 재생, 띵 소리 타이밍, 이어듣기 위치 저장 |
| `js/chime.js` | 띵 소리 (소리 파일 없이 코드로 만듦) |
| `js/backup.js` | 백업 파일(zip) 만들기·불러오기 |
| `js/images.js` | 표지 사진 크기 줄이기 |
| `js/webm-duration.js` | 녹음 파일에 길이 정보 넣기 (10초 뒤로·이어듣기가 잘 되게) |
| `js/wakelock.js` | 재생·녹음 중 화면 꺼짐 방지 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면에 앱으로 설치하기 위한 파일 |

빌드 과정이 없어서 파일을 고치고 올리면 바로 반영돼요.

---

## 2. 인터넷에 올리기 (GitHub Pages, 무료)

마이크를 쓰려면 `https://` 주소가 필요해서, 파일을 GitHub Pages에 올려요.

1. https://github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **+** → **New repository**
   - Repository name: 예) `voice-bookshelf`
   - **Public** 선택 (무료 계정은 Public 저장소만 GitHub Pages를 쓸 수 있어요)
   - **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 눌러요.
4. 압축을 푼 `voice-bookshelf` 폴더 **안의 내용물 전부**(index.html, css, js, icons, sw.js 등)를 끌어다 놓고 **Commit changes**.
   - `index.html`이 저장소 맨 위에 보여야 해요. 폴더째로 올려서 한 단계 안에 들어가면 안 돼요.
5. 저장소의 **Settings → (왼쪽) Pages**
   - Build and deployment → Source: **Deploy from a branch**
   - Branch: **main**, 폴더: **/(root)** → **Save**
6. 1~2분 기다리면 같은 화면 위쪽에 주소가 나와요.
   `https://내아이디.github.io/voice-bookshelf/`

> 코드는 공개되지만, 녹음과 사진은 태블릿 안에만 있어서 다른 사람이 주소로 들어와도 빈 책장만 보여요.

---

## 3. 태블릿에 설치하기

1. 태블릿 **크롬**에서 위 주소를 열어요.
2. 오른쪽 위 **⋮** 메뉴 → **홈 화면에 추가** (또는 **앱 설치**)
3. 홈 화면의 **목소리 책장** 아이콘으로 열어요.

앱으로 설치하면 주소창 없이 전체 화면으로 열리고, 브라우저가 녹음을 함부로 지우지 않는 '영구 저장'이 켜질 가능성도 높아져요.
(부모 화면 → 백업 칸 아래에서 영구 저장이 켜졌는지 볼 수 있어요.)

> ⚠️ 주소가 바뀌면(저장소 이름 변경, 다른 사이트로 이사) 저장 공간도 새로 시작돼요. 주소를 바꾸기 전에 백업 파일을 만들고, 새 주소에서 불러오세요.

---

## 4. 쓰는 법

### 부모: 책 넣기
1. 책장 오른쪽 위 **자물쇠를 3초 동안 꾹** 눌러요.
2. 처음이면 비밀번호 4자리를 정해요. 다음부터는 이 비밀번호로 들어가요.
3. **새 책 추가** → **사진 찍기**로 표지를 찍어요. (책 이름은 부모 화면에서만 보여서 비워도 돼요)
4. **녹음 시작** → 책을 읽어요.
   - 책장을 넘길 때마다 화면의 큰 노란 **책장 넘김** 버튼을 눌러요. 이 위치에서 아이에게 띵 소리가 나요.
   - 잘못 눌렀으면 **방금 넘김 취소**
   - 아이가 말을 걸면 **일시정지** → **이어서 녹음**
   - 녹음 중에는 띵 소리가 나지 않아요 (녹음에 섞이지 않게)
5. **녹음 끝** → **들어보기**로 확인 → **저장**

새 책은 책장 맨 앞에 꽂혀요. 순서는 부모 화면의 ↑ ↓ 버튼으로 바꿔요.

### 아이: 듣기
- 책장에서 표지를 누르면 바로 재생돼요.
- 큰 노란 버튼: 재생/멈춤 (표지를 눌러도 돼요)
- 왼쪽 ⏮: 처음부터 / 오른쪽 ↺10: 10초 뒤로
- 띵 소리가 나면 화면에 종이 뜨고, 아래 점이 다음 칸으로 넘어가요.
- 듣다가 나가면 노란 책갈피가 표지에 붙고, 다음에 누르면 멈춘 곳 2초 앞부터 이어서 들려줘요.
- 왼쪽 위 집 버튼이나 태블릿의 뒤로 가기 버튼으로 책장에 돌아가요.

부모 화면은 5분 동안 손대지 않으면 저절로 아이 화면으로 돌아가요 (녹음 중이거나 저장 안 한 책이 있으면 그대로 둬요).

---

## 5. 백업 (꼭 해 두세요)

녹음은 태블릿 한 곳에만 있어요. 몇 권 새로 넣을 때마다 백업해 두는 걸 추천해요.

- **만들기**: 부모 화면 → **백업 파일 만들기** → 태블릿 `다운로드` 폴더에 `목소리책장-백업-날짜.zip`이 생겨요.
  이 파일을 구글 드라이브나 컴퓨터로 옮겨 두세요.
- **불러오기**: 부모 화면 → **백업 불러오기** → zip 파일 선택.
  같은 책이 이미 있으면 백업 내용으로 바뀌고, 없는 책은 추가돼요.
- zip 안에는 `books.json`(책 정보), `audio/`(녹음, webm), `covers/`·`thumbs/`(표지)가 들어 있어요. 컴퓨터에서 열어 녹음을 따로 들을 수도 있어요.
- zip을 풀었다가 다시 압축하면 불러오기가 안 돼요. 처음 받은 파일 그대로 보관하세요.

부모 화면의 백업 칸에 마지막 백업 날짜와 그 뒤로 바뀐 책 수가 나와요.

---

## 6. 비밀번호를 잊었을 때

비밀번호 창에서 **비밀번호를 잊었어요** → 곱셈 문제(어른 확인)를 맞히면 새 비밀번호를 정할 수 있어요. 책과 녹음은 그대로예요.

## 7. 코드 고치기

GitHub 저장소에서 파일을 누르고 연필(✏️) 아이콘 → 고치기 → **Commit changes**.
1~2분 뒤 태블릿에서 앱을 껐다 켜면 반영돼요 (sw.js가 항상 새 파일부터 받아 오게 되어 있어요).

자주 바꿀 만한 곳:

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 띵 소리 음색 | `js/chime.js`의 `PARTIALS` (주파수, 크기, 사라지는 시간) |
| 띵 소리 크기 | 앱의 부모 화면 → 설정 (코드 수정 불필요) |
| 색 | `css/style.css` 맨 위 `:root` |
| 자물쇠 누르는 시간 | `js/app.js`의 `HOLD_MS` |
| 부모 화면 자동 잠금 시간 | `js/app.js`의 `PARENT_IDLE_MS` |
| 뒤로 가는 초 | `js/app.js`의 `player.back(10)` |
| 이어듣기 때 앞으로 당기는 초 | `js/app.js`의 `openBook` 안 `saved - 2` |

새 js 파일을 추가하면 `sw.js`의 `SHELL` 목록에도 넣고, `CACHE` 이름 끝 숫자를 하나 올려 주세요.

### 컴퓨터에서 미리 해 보기
`index.html`을 더블클릭해서 열면 동작하지 않아요. 폴더에서 간단한 서버를 켜고 열어요.

```bash
cd voice-bookshelf
python3 -m http.server 8000
# 크롬에서 http://localhost:8000 열기
```

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 녹음 버튼을 누르면 "마이크를 쓸 수 없어요" | 크롬 주소창 왼쪽 아이콘 → 권한 → 마이크 **허용**. 설치한 앱이면 태블릿 설정 → 애플리케이션 → 크롬 → 권한 → 마이크 |
| 소리가 안 나요 | 태블릿 **미디어 볼륨** 확인 (벨소리 볼륨과 따로예요) |
| 표지를 눌렀는데 재생이 안 되고 노란 버튼이 커졌다 작아졌다 해요 | 브라우저가 자동 재생을 막은 거예요. 노란 버튼을 한 번 눌러 주세요 |
| 녹음 중 "화면이 꺼져서 녹음을 잠깐 멈췄어요" | 다른 앱으로 가거나 화면이 꺼지면 녹음이 자동으로 멈춰요. **이어서 녹음**을 누르면 돼요 |
| 저장이 안 돼요 (공간 부족) | 태블릿 사진·동영상 정리. 녹음은 10분에 약 5MB예요 |

---

## 9. 나중에 폰에서도 듣고 싶어지면

저장하는 코드는 `js/db.js` 한 곳에 모아 두었어요. 이 파일의 함수들(`listBooks`, `getFile`, `saveBook`, `deleteBook` 등)을 같은 이름으로 Supabase 같은 인터넷 저장소에 맞게 다시 만들면, 나머지 화면 코드는 거의 그대로 쓸 수 있어요.
